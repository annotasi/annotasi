## Featured Work

### 🔖 [atbookmark](https://atbookmark-web-omega.vercel.app)
A bookmark management web app — organize, tag, and search saved links
without losing them in browser chaos. Built end-to-end: landing page,
auth, dashboard, settings, pricing/payment flow.
`atbookmark-web` (Next.js) · `atbookmark-service` (backend)

### 🗒️ Annotate
*(Built for Deloitte's internal Agentathon — repo private during the
program, details on request)*

An AI communication assistant for professionals working across language
and culture — bilingual meeting/message comprehension, a "draft coach"
for outgoing messages, and a personal vocabulary that compounds over
time instead of resetting every session. Hexagonal architecture, Spring
Boot backend, React frontend, built solo end-to-end.
